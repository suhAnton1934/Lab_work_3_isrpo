# Smart Loop Generator

Плагин для VS Code, который генерирует разные циклы с разными выходными данными в зависимости от двух введенных пользователем значений

## Описание 

Плагин запрашивает у пользователя два числа — `x` и `y`, анализирует их
и в зависимости от результата сравнения генерирует код с одним из двух циклов:

- ***Если `y >= x`*** — используется цикл `while`, выводящий квадраты чисел
  в диапазоне от `x` до `y`.
- ***Если `y < x`*** — используется цикл `for`, выводящий кубы чисел
  в диапазоне от `y` до `x`.

Сгенерированный код вставляется в позицию курсора активного редактора.

## Возможности плагина

- Автоматический выбор типа цикла (`while` или `for`) по математическому условию.
- Сбор результатов в массив (`number[]`) для дальнейшей обработки.
- Хранение шаблонов кода в `Map<string, string>`. Это позволяет реализовать динамический выбор шаблонов.
- Вставка готового кода прямо в редактор.
- Обработка краевых случаев (пустой ввод, ввод не числа, пустой диапазон генерации кода)

## Использование плагина

1. Установите курсор в нужное место.
2. Откройте палитру команд (`Cmd+Shift+P`).
3. Введите `Smart Loop` и выберите команду
   **«Smart Loop: генерация циклов по числовым значениям x и y»**.
4. Введите число `x`, затем число `y`.
5. Сгенерированный код появится в редакторе.

## Пример работы плагина

### Входные данные
x = 3\
y = 7

### Условие проверки и выбор фрагмента кода
`y >= x` → `7 >= 3` → **true** → ветка `while`.

### Сгенерированный код
```javascript
let i = 3;
while (i <= 7){
	console.log(i*i);
	++i;
}
// Сгенерировано чисел: 5
```
