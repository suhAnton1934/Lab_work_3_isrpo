# Smart Loop Generator

Плагин для VS Code, который генерирует разные циклы с разными выходными данными в зависимости от двух введенных пользователем значений

## Описание 

Плагин запрашивает у пользователя два числа — `x` и `y`, анализирует их
и в зависимости от результата сравнения генерирует код с одним из двух циклов:

- ***Если `y >= x`*** — используется цикл `while`, выводящий квадраты чисел
  в диапазоне от `x` до `y`.
- ***Если `y < x`*** — используется цикл `for`, выводящий кубы чисел
  в диапазоне от `y` до `x`.

Сгенерированный код вставляется в позицию курсора активного редактора.

## Возможности плагина

- Автоматический выбор типа цикла (`while` или `for`) по математическому условию.
- Сбор результатов в массив (`number[]`) для дальнейшей обработки.
- Хранение шаблонов кода в `Map<string, string>`. Это позволяет реализовать динамический выбор шаблонов.
- Вставка готового кода прямо в редактор.
- Обработка краевых случаев (пустой ввод, ввод не числа, пустой диапазон генерации кода)

## Использование плагина

1. Установите курсор в нужное место.
2. Откройте палитру команд (`Cmd+Shift+P`).
3. Введите `Smart Loop` и выберите команду
   **«Smart Loop: генерация циклов по числовым значениям x и y»**.
4. Введите число `x`, затем число `y`.
5. Сгенерированный код появится в редакторе.

## Пример работы плагина

### Входные данные
x = 3
y = 7

### Условие проверки и выбор фрагмента кода
`y >= x` → `7 >= 3` → **true** → ветка `while`.

### Сгенерированный код
```javascript

while (i7 <= 7){
	console.log(i*i);
	++i;

# extension

## Основная функция плагина. В ней осуществляется последовательное выполнения 
	функций, представленных после главной функции

## Функция принимает значение x_str в формате string и преобразует его в число x

	Входные данные:
		x_str - вводимое строковое значени
	Выходные данные:
		x - десятичное число

## Функция принимает на вход два числа, сравнивает их и в зависимости от результата сравнения 
	возвращает true/false 
	Входные данные:
		x, y - десятичные числа
	Выходны данные: 
		true, если y >= x, и false, если y < x

## Функция добавляет в массив квадраты чисел в диапазоне от x до y
	Входные данные:
		x, y - десятичные числа
	Выходные данные:
		numbers - массив, все элементы которого являются квадратами чисел из диапазона от x до y

## Функция добавляет в массив кубы чисел в диапазоне от y до x
	Входные данные:
		x, y - десятичные числа
	Выходные данные:
		numbers - массив, все элементы которого являются кубами чисел из диапазона от y до x

## Функция генерирует код, который позже будет выводиться в саму программу. Разный код генерируется
	с помощью функции Map<string, string> - с ее помощью программа понимает, какой именно фрагмент 
	кода нужно сгенерировать.
	Входные данные:
		x, y - десятичные числа
		branch - переменная, принимающая булевые значения true/false и отвечающая за выбор сгенерированного кода
		result - массив, который выводится из функций WhileLoop и ForLoop
	Выходные данные:
		code - сгенерированный код в виде строки

## Функция получает на вход строку, состоящую из кода, который нужно вывести.
	Проверяет, есть ли активный редактор кода. Если нет, выводит ошибку на экран, если есть, 
	запускает editor.edit() и вставляет готовый код после курсора

	Входные данные:
		code - строка, в которой хранится уже готовый код
	Выходные значения:
		в саму программу выводится готовый код, который генерируется по двум числовым значениям
